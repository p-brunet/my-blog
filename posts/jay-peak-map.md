# JayPeakMap: Topographic Maps of Jay Peak from LiDAR Data

**GitHub**: [p-brunet/JayPeakMap](https://github.com/p-brunet/JayPeakMap)

## Overview

This project generates minimalist topographic contour maps of Jay Peak (Vermont, USA) from publicly available LiDAR elevation data. The goal: produce a map clean enough to print as a large-format poster at 300 DPI.

![Final poster](https://raw.githubusercontent.com/p-brunet/JayPeakMap/main/jay_peak_poster.png)

## Data Source

Elevation data comes from the **Vermont Center for Geographic Information (VCGI)**, which publishes LiDAR surveys at **35–70 cm resolution**. The data is freely available and in the public domain.

## Pipeline

The workflow runs in four steps:

1. **LiDAR tile loading** with `rasterio` — read and reproject the raster files
2. **Peak extraction** by GPS coordinates — locate the highest pixel within a buffer around the summit
3. **Intelligent downsampling** with `scipy` — reduce resolution to speed up rendering without losing the terrain shape
4. **Contour generation** with `matplotlib` — variable line weights for visual polish

```python
import rasterio
import numpy as np
import matplotlib.pyplot as plt
from scipy.ndimage import zoom

# Load LiDAR raster
with rasterio.open("jay_peak_lidar.tif") as src:
    elevation = src.read(1)
    transform = src.transform

# Downsample
elevation_small = zoom(elevation, 0.1)

# Contour plot
fig, ax = plt.subplots(figsize=(12, 12))
ax.contour(elevation_small, levels=50, colors="black", linewidths=0.5)
ax.axis("off")
plt.savefig("jay_peak_contour.png", dpi=300, bbox_inches="tight")
```
